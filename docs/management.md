# 管理中心

界面采用左侧可折叠导航、分组配置和状态卡，保留九个正式管理页面。导航折叠偏好在本机保存；操作显示处理中、成功或失败反馈。扫描进度自动更新，但不会重建正在填写的范围与作者输入。JSON 只作为可展开的高级明细，默认显示可读摘要。

概览页的更新按钮统一进入“扫描与检查”，不会另起一套扫描流程。扫描页顶部提供九平台多选、全选和清空；首次打开默认选中有效平台，之后在本机记住有效的选中 ID。日常“更新图库”是一键增量更新，空选择会禁用按钮且不会静默扩大到全库。图库源始终只读，普通更新自动带上只读保护，不再重复勾选确认。全量重提取、指定平台或作者范围位于折叠的高级更新区，提交前显示页面内确认区；取消或未确认不会启动扫描，不依赖内嵌浏览器的原生确认弹窗。

正式 `Gallery.exe` 包含本机管理中心；浏览器 `/manage` 保持只读，不获得这些权限。Electron 只承载界面、目录选择和调用本机用例，不读取 SQLite。

配置中的“实时提交”开启后，先重启再扫描；已确认作品可边扫描边展示。概览显示实时修订号，扫描的准备阶段显示“准备中”。数据版本页提供需停服、需勾选确认的实时库重置，原库保留在实例 temp 备份。普通静态 READY 扫描由 Runtime 后台校验并接入，接入等待不要求重启；只有应用失败或实时检查点待恢复时才进入诊断/恢复，显式回滚仍按页面提示重启。详见 [实时更新](live-updates.md)。

| 页面 | 能力 |
|---|---|
| 服务概览 | 启动、停止、重启、连接独立 Runtime、打开画廊、进入统一扫描页和查看进度 |
| 配置 | 九平台源、只读文件浏览根、监听/Host/Origin、短链、保留策略；校验、修订冲突检测、保存前备份、备份载入草稿 |
| 扫描与检查 | 顶部多选平台的一键增量更新；高级全量／单平台／单作者更新；作者目录查找；取消、独立只读抽查、报告摘要 |
| 图库验证 | 选择检查项、限定平台、取消、问题筛选／分页／本机定位、JSON/CSV 导出和报告清理 |
| 数据版本 | READY 校验、发布、回滚、保守清理计划和执行；静态发布由 Runtime 后台接入，异常恢复按页面状态处理 |
| 日志 | 有界轮转、级别／关键词过滤、跟随最新、打开本机日志目录；停服后清空选定日志 |
| 访问与客户端 | 本机可见地址、持久有界访问摘要、错误和活动连接、封禁／解除；本机和代理不能封禁 |
| 存储 | 实例占用、孤儿缓存检查／选择性清理，以及明确确认后清空全部缩略图 |
| 诊断 | 源根/工具可用性、完整 generation 校验、聚合诊断报告导出到实例 reports |

配置更改不会直接修改源或数据库。图库根改变需要重新构建完整候选；监听等设置重启后生效。实例目录与内部布局不能从此处原地迁移。配置备份属于私有实例，不进入公开仓库或诊断导出。

日志不把私人正文、URL 查询或凭据复制到界面/报告；非结构化行显示隐藏提示。服务和扫描日志按 8 MiB、5 个历史块轮转。访问历史保存在实例 state，最多 256 个客户端、200 个事件、30 天未活动保留；重启恢复计数和封禁，但活动连接归零。地址仅通过已授权本机管理通道显示，不进入公开 HTTP；事件不保存 URL/查询/正文，不冒充代理背后的身份。

指定范围检查仍是**只读抽查**，最多 1000 个作品；与会生成候选版本的增量／定向更新明确分开。增量仍安全枚举所选范围，但满足物理指纹和版本条件的未变化作品可走 Catalog/Search 快路径；变化、删除、作者/标签变化仍按完整结果重建。较旧的 contentless Search 首次升级需要完整构建，规则/Adapter/shape/source-root 变化也会明确回退到 full；`effectiveMode`、`fallbackReason`、复用/重建计数会进入状态和报告。Manager 状态卡显示 `status.scan.search` 的构建、复用、更新和移除聚合；最终报告使用 `searchBuild` 保存增量构建细节，`report.search` 仍是 manifest facts。因而不能把每次增量描述成“所有 metadata 都重新解析”或“Search 必然全量重建”。通用断点续扫、旧 Rules DSL、动态平台及旧数据库入口不恢复。

图库验证使用新物理事实检查，不把 metadata 缺失当作作品不存在，也不把合法深层附件当成错误。问题记录最多 100000 条，达到上限明确标记；原始 metadata 不进入报告。相对路径只留在本机私有报告中。验证与扫描互斥，源只读。

选择性缓存清理只删除有来源记录、且再次确认源文件不存在的缩略图。旧缓存没有来源记录时标记 unknown 并保留；命中旧缓存时补写本机来源记录。清理需停服且没有扫描，永不删除源或 READY 数据库。

测试专用回环 Manager 入口见 [测试管理器](test-manager.md)，它不是正式 Runtime 的管理 HTTP 接口。

日志默认脱敏；用户可在本机管理页明确确认后显示有界原始尾部日志。该选项不对公共 HTTP 开放，也不进入诊断导出；自动验收不得在真实实例启用它或读取私人日志内容。

全库取消通过实例内请求文件在安全检查点处理，不强杀 writer。发布提交阶段拒绝取消；完成但尚未发布的候选可能保留，当前已发布代不受取消影响。任何 REQUIRED filesystem 不完整仍不能发布。

管理用例位于 `internal/runtime/management.js`，由本机 CLI `manage <operation>` 以有界 stdin JSON 调用。实时访问控制走已有带实例 token 的命名管道。管理接口不新增公网 HTTP 入口。清理/保存/版本变更重新核验实例路径和状态，危险操作要求明确确认。
