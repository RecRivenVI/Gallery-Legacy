# 更新和管理画廊

你可以在“更新图库”选择平台，再更新所选内容。空选择不能开始；日常更新只处理变化的作品，“全部重新扫描…”会重新读取全部平台。

| 页面     | 你能做什么                                                     |
| -------- | -------------------------------------------------------------- |
| 更新图库 | 启停服务、选择平台、更新、全部重新扫描、查看进度和停止更新     |
| 访问     | 按时间查看访问记录、封禁或解除封禁；本机地址不能封禁           |
| 设置     | 调整目录和网络设置；保存失败保留输入，需要重启时按钮会说明     |
| 排查     | 阅读中文日志摘要、展开原文、检查图库和运行环境、清理缩略图缓存 |

更新时你可以继续浏览；有新内容时点击提示查看。停止更新保留已经完成的作品，不删除原文件。

“访问”中的封禁开关立即生效，不经过保存条。退出管理窗口与停止服务不是同一操作；是否继续后台运行以托盘操作为准。出现错误时按提示重试，仍失败再到“排查”查看对应说明。
