# 更新和管理画廊

你可以用管理器启停服务、更新图库、管理访问和设置，以及排查问题。当前页面与功能状态见[产品总览](../project/overview-gallery.md#管理访问与实例)。

平台/作者范围、全量/增量、独立封面任务和自动刷新统一见[更新图库与封面](guide-scanning.md)。

“设置 → 缩略图”可选择 FFmpeg 路径，调整中、大缩略图缓存上限。

“访问”中的封禁开关立即生效，不经过保存条。出现错误时按提示重试，仍失败再到“排查”查看对应说明。

关闭窗口会收起到托盘，重新打开后可以继续操作。托盘中选择“退出”会停止更新并结束画廊服务；已经完成的作品保留，重新打开后仍可使用。画廊与扫描只能在管理器内启动。服务行读取失败时不会继续显示旧的运行状态。

“对外地址”供 Venera 使用，只在“局域网”或“公网”模式下编辑。

图库检查结果可以按路径和级别筛选、翻页，并导出 CSV 或 JSON。托盘可以启停或重启画廊、打开各数据目录；“关于画廊”中列出版本和字体。

长平台名称会在右侧淡出，数量保持可见。“排查”的缓存大小会按 MB 或 GB 显示；没有缓存时直接显示“没有缓存”。

“设置 → 账号”列出本机账号，可重设密码或删除账号。删除会同时移除该账号的收藏、评分和阅读记录，作品文件仍保留。
