# 更新图库与封面

你可以选择平台进行全量或增量扫描，也可以在“作者扫描”中只处理一个作者。平台选择会记住。

- 增量扫描：重新处理新增、文件大小或修改时间变化的作品。
- 全量扫描：重新读取所选范围的全部作品。

点击开始后，确认面板会列出本次模式和范围。文件清单服务不可用时，由你选择是否改为遍历目录。扫描状态显示作品和作者进度，以及失败和警告。停止扫描会保存已经处理完成的作品，下次增量接着处理未完成部分。

新作品分批显示。“自动刷新”默认开启，每五秒刷新有变化的列表，可以在画廊设置中关闭；新内容提示仍保留。

在“封面生成”选择平台，或按“平台/作者目录名”逐行填写作者，手动生成新增、变化或全部封面。扫描期间不能新开封面任务，已有任务会暂停，扫描结束后由你手动继续。全部文件只在浏览时生成预览。视频时长与成功生成的封面一起出现。

“访问”中的“自动封禁”默认关闭。你可以设置统计时长、请求数或错误数上限，以及封禁时长；本机地址不会被封禁。
