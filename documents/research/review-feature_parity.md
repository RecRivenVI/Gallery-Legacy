# 旧产品与当前架构功能对照

2026-11-03

## 问题

10-26 的合成场景不足以证明完整迁移。此表是唯一功能对照来源，以旧产品报告的 F01–F65（原文无 F34）、72 行覆盖清单及冻结代码 `20ff819` 为标准；冻结设计和后续用户决定高于旧布局。差异分为迁移遗漏、明确设计变更、原版已有局限。未有真实运行证据的结论仅表示静态行为对照，不表示实际设备验收。

## 方法

逐行核对旧报告的触发、输出与边界，查阅冻结旧代码和当前实现；保留旧规则已放弃的功能为“不存在一致”，不把它们当待建功能。可用现有布局补齐的遗漏纳入本轮；需要新界面且与冻结设计冲突的部分列在结论，不恢复九页管理器。

## 结论

范围冻结：补旧链接、检查结果完整访问和托盘遗漏；其余明确设计变化不回填旧页面。C35/C38/C59 以本轮扫描场景为准。非法百分号 URL 在 Go 路由前返回 400 的纯文本正文，与旧 Node JSON 有差异（C50），不自写 HTTP 解析器；正常网址错误仍遵循 JSON 合同。需要用户决定的是已移除的管理操作是否需要新的界面入口；本轮不擅自恢复旧九页和额外确认框。
