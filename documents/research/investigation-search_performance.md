# 可见字段与组合搜索性能

2026-11-03

## 问题

同一约 39 万合成查询语料上，默认中文短词查询原先需要数秒。第二阶段增加多词、排除和跨平台条件，必须保持精确计数及可见字段语义。

## 方法

使用 tools/searchbench 构造纯查询语料：390,000 个作品，微博 270,000。没有来源文件、原图或真实 metadata。每场景先一次预热，再保留九次样本；p95 取九次中的最大值。测量期间不并行构建、浏览器验证、其他测试或清理。命令从仓库根目录执行；`<corpus>` 是仓外合成语料，`<result>` 是仓外结果 JSON：

```powershell
node tools/go/run.mjs run ./tools/searchbench -root <corpus> -output <result>
```

## 发现

| 场景 | 原查询 p95 ms | 最终 p95 ms | 结论 |
| --- | ---: | ---: | --- |
| 普通浏览 | 82.22 | 35.42 | 一致，结果语义保持 |
| 中文短词 | 7432.77 | 538.22 | 一致，移除大正文投影的关联开销 |
| 中文单字 | 7286.49 | 551.13 | 一致 |
| 常见拉丁词 | 765.78 | 658.82 | 一致 |
| 稀有标题 | 863.35 | 147.50 | 有差异，按决定不再命中隐藏 ID，2 个结果变 1 个 |
| 作者名 | 616.93 | 188.03 | 一致 |
| 标签 | 477.61 | 93.47 | 一致 |
| 深页 | 117.72 | 89.41 | 一致 |

新增语法不能拿旧的字面字符串结果作为同义基线，结论是无法比较：最终多词 p95 648.17 ms，多平台 775.49 ms，包含与排除 575.11 ms，精确来源 ID 127.69 ms，多标签 97.83 ms。中间版本的多词为 1066.35 ms，精确 ID 263.88 ms；合并紧凑字段核验并下推平台范围后达到事先定义的目标。保留所有测量样本，不只选最快的一轮。

## 结论

最终样本达到 adr-13 的查询目标。只证明查询、精确计数与 48 张卡片 DTO；不代表 HTTP、缩略图、浏览器、真实图库、扫描或 HDD 性能。语料的短词索引为安全超集，精确文本复核仍保留；它不是实际数据分布或统计显著性证明。
