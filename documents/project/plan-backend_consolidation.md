# 后端收敛

## 目标

交付同一次构建的便携候选和回退入口，保留实例配置、目录、个人数据与已提交成果。真实图库升级、增量、微博全量和封面生成留给用户验收。

## 范围

识别与复用、NTFS 清单与日志、扫描流水线、双库缩略图及旧记录导入。沿用现有 Go、Tauri、Compose 架构与 Go 1.27.2。自动验证使用 SSD 合成数据，生产和正在使用的实例保持隔离。

## 步骤

1. 完成：精确 ID、发布时间与后备字段修订，部分识别的完整提交可复用。
2. 完成：真实 NTFS 合成目录的原生对照与 USN 重放，移除 Everything。
3. 完成：数据库批量复用、机械盘读取与入库解耦的合成验证。
4. 完成：双库缩略图、暂停恢复和原图加载的两端运行对照。
5. 完成：隔离实例演练旧报告与访问记录导入，核对失败和重复导入。
6. 完成：在冻结候选上运行隔离验收，核对程序与 ZIP，归一便携入口。

## 结果

合成验收结论归入[当前进度](status-repository_standard.md)。真实图库升级、增量、微博全量和封面生成待用户试用。
