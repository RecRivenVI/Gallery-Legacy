# 扫描与任务整理

## 目标

交付可供人工验收的新便携版：空 Instance 保持真实平台根目录并补齐授权配置；扫描、封面任务、数据来源与访问控制符合 2026-11-04 用户决定。本地提交，不推送，不扫描真实图库。

## 范围

范围以 [adr-14](../design/adr-14-scan_inventory.md) 为准。生产实例不动，历史仓外资料仅盘点。所有自动验证在 SSD 合成实例执行。

## 步骤

1. 完成：核对入口、清单、事务、预生成和诊断，记录架构决定与范围。
2. 完成：持久文件清单、文件属性逐项比较、受控回退、调度、部分取消收尾与进度。
3. 完成：移除元数据文件声明与关联候选；视频事实随缩略图生成；压缩包事实。
4. 完成：独立手动封面任务、自动封禁、必要两端界面及自动刷新。
5. 完成：诊断与日志收敛，列出仓外历史占用与建议。
6. 完成：合成回归、浏览器截图自查、构建便携版、补齐空实例配置和人工验收清单、本地提交。

## 结果

已完成实现、合成对照、实际 Tauri 与浏览器验证、便携构建和实例配置核对；交付等待人工验收。部分取消、清单不完整、读取/发布顺序与有界暂存三处风险均有针对性回归。实际 HDD 收益、首次真实扫描和真机仍未验证，详见[当前进度](status-repository_standard.md)。
