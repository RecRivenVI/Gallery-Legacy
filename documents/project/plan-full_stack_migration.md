# Go、Tauri 与 Compose/WasmJS 完整迁移

## 目标

## 范围

- 保留九平台、SQLite 格式、公共 URL、Venera、源只读、单 writer、WAL/FULL、恢复及管理器绑定生命周期。

- 仅使用隔离合成实例验证；现有生产、历史 Runtime、完整／空设计沙盒不修改。构建与证据放在仓库外。
