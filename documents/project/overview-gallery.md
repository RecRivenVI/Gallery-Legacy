# 产品总览

画廊把固定九平台的本地作品整理成可搜索、可阅读的个人图库，供拥有者和少数可信的浏览者使用。先在桌面管理器配置目录、选择范围并扫描，再用网页画廊浏览作品、作者和标签，打开图片、动图、视频或漫画。管理器负责服务和任务；关窗收进托盘，真正退出时正常结束服务与扫描。来源文件始终只读。

当前候选采用 Go 业务后端、Tauri 桌面宿主，以及网页画廊和管理器两端 Compose/WasmJS 界面，版本取自 [Cargo.toml](../../src-tauri/Cargo.toml)。Windows x64、WebView2 和支持 WasmGC 的现代浏览器是当前目标，其他系统没有发行验收。**实现、自动证据与用户验收是三个不同状态**，当前候选仍等待真实试用。

## 使用入口与状态口径

- 日常使用：管理器启动画廊 → 选择平台增量更新 → 浏览或搜索 → 阅读作品。首次建库或重新解析指定范围时使用全量扫描。
- 个人阅读：访客可以浏览；本地账号保存偏好、收藏、评分、个人标签、历史和继续阅读。
- “全部文件”：直接浏览另外配置的目录，不进入作品数据库，也不是第十个平台。
- 体验入口：现有便携候选、真实路径空 Instance 和固定内容合成试用实例均保留。程序身份与仓外材料位置只在仓外交付/整理索引记录，本页不维护本机路径。

以下“已实现”指当前代码有入口或处理路径；“已有自动证据”仅指[当前进度](status-repository_standard.md)声明的场景，不代表全部组合已经验证。真实试用、已确认但未完成、待定与明确不做分开列出。历史构想不会因记录在此而自动成为实施任务。

## 平台、作品与文件事实

已实现：pixiv、pixivFANBOX、Gank、Fantia、Patreon、Pawchive、X、微博、Venera 九个平台，目录与解析规则写死，不做动态平台注册或通用规则系统。

- 文件名、大小、媒体数量、媒体类型和压缩包存在事实来自磁盘；metadata 只补作品、作者和平台资料。坏或缺 metadata 时保留物理实体并使用目录/文件名，不按字符串内容过滤合法资料。
- 提取标题、正文、标签、作者、作品类型、系列、收藏/浏览/评论等指标、工具、付费档位、语言和地区。不同平台按实际资料提供，不伪造缺失值，精确定义见[字段定义](../reference/schema-metadata_enrichment.md)。
- pixiv 区分全年龄、R-18、R-18G 和 AI 标记，其他平台不强套同一分级。作者资料从较新作品中提取；头像默认隐藏，开启后用占位图，不用作品冒充头像。
- 元数据声明的媒体列表已停写并清理，不再做“元数据声明存在但磁盘缺失”的对照。视频时长从视频文件取得，与封面一起出现，其他角标独立显示。
- 自动作者关联仅 pixiv ↔ pixivFANBOX；其他平台手动关联，不生成关联候选。关联是图库资料，不属于个人收藏数据。
- 全部文件允许根目录包含平台目录，但隐藏已索引的平台入口，不把有意隐藏记成错误。只实时生成并缓存预览，不提供预生成。
- 各平台记录压缩包存在情况；Gank 既有 mega/压缩包预览规则保留，资源细分类待实地考察决定。

已有自动证据：九平台合成解析、坏/缺 metadata 保留、清除旧声明仍保留实际媒体及稳定身份、视频时长随封面发布。真实目录形态、资料质量与第三方客户端使用原始/清洗数据仍待真实试用。

## 扫描、进度与封面任务

已实现流程以 [adr-14](../design/adr-14-scan_inventory.md) 和[文件清单机制](../design/mechanism-inventory.md)为依据：

- 全量/增量均可多选平台并记住选择；启动前展示模式和范围并确认。作者扫描有独立页面，Venera 不进入；**作者范围正确性仍有阶段三待处理项，不写成已完全验收**。
- 优先取得 Everything 清单，不可用或不能确认清单可用时提醒，经用户同意才原生遍历，禁止静默回退。
- 清单逐文件比较路径、大小和修改时间，不算内容哈希，不以文件夹时间判断变化。增量复用未变作品；变化以完整作品为单位替换，作者增删可整组处理。内容替换但大小和修改时间均未变的情况不检测。
- 全量直接重扫所选范围，逐作品替换，完整结束后才核对删除，删除前原生确认确实不存在。作品、清单、搜索、计数与 revision 一致提交，保持 SQLite 单 writer、WAL/FULL。
- 作品准备好即分批入库，巨无霸作者也不等整位作者完成。取消停止准入并收尾已准备内容；未扫到、未完成和解析失败作品不推进清单，留给下次增量。
- SSD 按清单规模安排平台/作者顺序与有界并发。每块 HDD 一个读取者，不同盘可并行；平台内尽量按物理位置读 metadata，作者顺序只决定提交/显示先后。未知位置仍处理并记录警告。
- 两端显示进度；画廊平台入口下方分作品、作者两条，管理器提供数量、阶段、失败/警告及全部问题分页。阶段计时、metadata 读取次数和平均耗时写入日志。
- 封面生成是独立手动任务，支持全量/增量及平台/作者范围；扫描时暂停且不能新启动，结束后由用户手动继续。HDD 预生成单线程按物理顺序读源图，实时生成不要求物理顺序。
- 画廊默认五秒合并自动刷新，可关闭；“有新内容”提示条保留。刷新允许内容移位，不整页重载；管理器更新状态而非整页重建。

已有自动证据：[扫描任务](../../validations/scene-scan_tasks/validation.md)和[连续更新](../../validations/scene-live_updates/validation.md)覆盖未变复用、变化替换、失败重试、不完整清单不误删、部分取消、大作者提前可见、大作品有界暂存、读取/提交顺序及两端响应。小型 SSD 合成测量不证明真实大库、冷 HDD 或长期运行表现，适用边界见[进度](status-repository_standard.md#验证边界)。真实扫描准备阶段及调度问题留待阶段三，本轮不修。

## 浏览、搜索与筛选

已实现：平台作品、作者、作者作品、全部页、标签和全部文件入口；作者页提供资料、统计、作品与关联。没有无条件聚合所有平台作品的首页，跨平台混合结果由搜索条件触发。

- 网格/列表、卡片大小、1:1 / 4:3 / 3:4 / 16:9 / 9:16 比例，每页 24/48/72/96/120；玻璃页码条支持滚动、跳页、越界退到末页，翻页保持条件，预取下一页封面。
- 默认搜索卡片可见的标题、作者、标签；空格多词同时满足、引号连续匹配、减号排除，以及标题、作者、ID、作者 ID、标签、正文和个人标签等字段前缀。精确标签包含/排除与关键词搜索分开。
- 高级搜索提供分字段输入与多平台选择；筛选作品类型、pixiv 分级/AI、付费、日期、页数及个人收藏/评分/已读。可按平台指标和个人数据排序，跨平台只保留共同适用项。
- 停止输入后自动搜索，输入法拼写中不触发，回车立即执行，`/` 聚焦搜索框。条件写进 URL，翻页、跳页、刷新与后退保持，一次输入会话不产生逐字历史。
- 深浅主题、背景与淡化、侧栏收起、手机抽屉、减少动态效果、加载/空/错误/重试状态；隐私模糊仅影响卡片内封面和信息。可隐藏无可看内容的作品，头像默认不显示。
- MiSans 官方子集、Emoji 和小语种字体本地按需加载，运行时不访问字体 CDN；使用 Fluent System Icons，不引入 Miuix 组件库。

已有自动证据：[分页搜索](../../validations/scene-pagination_search/validation.md)、[约 39 万作品检索](../../validations/perf-search/validation.md)、[字体](../../validations/scene-portable_fonts/validation.md)和两端合成画面。查询耗时不代表扫描或完整交互耗时。中文输入法、实际字形、手机/平板手势及响应式体验仍待人工试用，本轮没有重跑画面或性能检查。

## 看大图、媒体与个人阅读

已实现：卡片到看大图的开关过渡、作品内翻页与跨作品、缩略条、详情、缩放/拖动、隐藏工具、宽屏分栏；窄屏完整看大图。原图先显示预览，有等待和失败状态；详情正文为纯文本，网址可点击，支持作品链接/短链复制和下载。

方向键翻页、Shift 加方向键换作品、Esc 关闭、I 详情、H 隐藏工具；双击缩放，触屏滑动与双指缩放。视频使用浏览器解码/控件，支持循环与按文件名寻找字幕，格式支持受浏览器限制，不宣称 VLC 兼容。

漫画支持单页、双页、纵向连续、从右到左和封面单独；漫画按设备选择默认模式，可手动切换。系列边缘可进入上一话/下一话。本地多账号提供可选密码、收藏/收藏夹、评分、个人标签、历史、继续阅读和偏好；可关闭后续历史记录。管理器可重设密码、删除账号。个人记录按作品目录关联，目录改名不自动迁移记录。

已有自动证据：[个人阅读](../../validations/scene-personal_reading/validation.md)、[画廊场景](../../validations/scene-gallery/validation.md)和历史迁移对照。MediaSession 等未恢复细节仍待决定，不能以“可播放”代表原有细节已齐。操作见[阅读指南](../usage/guide-gallery.md)。

## 管理、访问与实例

当前有“更新图库、作者扫描、封面生成、访问、设置、排查”六个入口，不再是旧总账中的四页。提供服务控制、任务/问题详情、访问记录和封禁、设置草稿/保存/冲突提示、日志中文摘要/原文/筛选、图库检查及 CSV/JSON 导出、运行环境与缓存清理。

自动封禁默认关闭，窗口、请求/错误阈值与封禁时长可调，本机地址不能封；封禁立即生效，不经过设置保存条。产品清理自身缓存、临时文件、轮转日志与旧数据版本直接删除，Agent 开发清理仍必须进回收站。

支持本机/局域网/公网浏览模式、publicUrl、Host/Origin 白名单、短链和 noindex。管理操作限本机宿主；Venera 源由服务分发，提供九平台分类/搜索/章节，只读数据库，不回退到文件系统。精确标签预设等未补齐细节仍在待定项。

便携包包含程序及必要资源，管理 UI 嵌入 Gallery，网页 UI 嵌入 Go runtime；exe 旁实例指针指向外部配置，数据库、缓存和个人数据放实例目录。候选保持独立端口和真实路径空工作库，不替换生产，合成试用实例另行保留。任务属于管理器，隐藏不结束任务，真正退出协作取消并等待子进程结束。

已有自动证据：SSD 合成管理任务、自动封禁、升级/恢复约束和实际 Tauri WebView 联调。系统托盘、目录对话框、原生输入法、系统字号、读屏、完整 RTL、真机及生产替换没有完整验收。诊断现状见[诊断审计](../research/audit-diagnostics.md)，该审计保留历史结论，仓外处置以本次整理索引为准。

**仍待用户决定**：旧管理维护入口、浏览细节、压缩包分类与界面专项。逐项清单统一在[待办](backlog-runtime.md#待真实试用与用户决定)，不在总览复制维护。视频时长、作者扫描、自动封禁已经进入实现，不能继续沿用旧总账的“未开始”。

**另行授权**：Runtime 归并、替换生产、签名/自动更新，以及 Legacy 完善后迁往独立 Gallery 的时间与方式。gallery-dl 集成和下载校验只是后续方向，下载器保持独立。

**明确不做**：文件变化自动扫描、文件内容哈希兜底、跨平台重复图检测、标签翻译、VLC/自主媒体引擎、社交、多租户、OAuth/RBAC 公网权限体系、动态平台/DSL/插件、无条件的全部平台作品页、浏览器 `/manage` 管理入口、微博\_Legacy 独立入口；不恢复 Node/Electron 产品或已放弃客户端分支。下载器、pixiVenera 和独立 Gallery 都不是本仓库的组成部分。
