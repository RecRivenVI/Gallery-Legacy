# 后续工作

只记录用户方向与必须补齐的能力，不表示现在获得实施授权。

| 事项                | 当前边界／开始条件                                                                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 完整 Go 后端        | 公共读取已经独立接入；任务、本机认证、所有权、动态恢复切换、生命周期及默认入口替代仍待后续检查点                                                                                    |
| WasmJS 与 Tauri     | 按[92 号决定](../design/adr-7-wasmjs_scope.md)仅采用相同底层栈，排除 Miuix 组件／视觉；[补充评估](../research/survey-wasmjs_stack_scope.md)列版本、胶水与次序的剩余选择，不自动切换 |
| 非法 URL 错误正文   | Go HTTP parser 提前返回 400，不带 Node v1 envelope；正常前端不会生成该请求，后续决定是否接受标准库行为，见[接入边界](../design/architecture-http_read.md)                           |
| 自主媒体查看器／VLC | 先定解码／输出与许可边界，不假定可以把 VLC 全部搬到浏览器                                                                                                                           |
| 大作品通道          | 需要有界 spool 与失败／恢复测试，不提高内存上限充当解决                                                                                                                             |
| 字体与真机          | 先定正式分发，再核对字形、RTL、缩放／读屏和手机平板；未实测不记通过                                                                                                                 |
| Runtime 归并        | 本轮排除。单独授权后核对归属、占用、冲突和台账，不能擅停服务                                                                                                                        |
| 手机网格性能        | 默认两列与同源占位已修正；更多可见卡片的移动模拟抽查存在额外开销，后续在完整素材与真机上核对，不据模拟结果宣布达标                                                                  |
| 日志时间显示        | 新合成实例的服务启动日志可显示中文摘要，但时间列为“—”；需统一日志时间字段合同，不把摘要可读误记成日志展示完整                                                                       |
| 独立 Gallery        | 用户要求暂缓该仓库开发，等本项目完成后再决定迁哪些代码；不假定数据库／协议兼容                                                                                                      |

具体存量违规与影响见[技术债](debt-runtime.md)。
