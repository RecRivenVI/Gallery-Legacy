# 后续工作

当前产品范围见[产品总览](overview-gallery.md)，实现与验证结论见[进度](status-repository_standard.md)。旧功能总账已按当前候选归入总览；本页是未决事项的唯一入口，不把旧设计提议自动变成实施任务。

## 待真实试用与用户决定

以下不自动获得实施授权；曾提出的功能不等于已经决定恢复。

| 事项                  | 边界                                                                                                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用户体验验收          | 检查两端当前视觉、系统输入法、托盘与目录对话框；反馈不自动视为所有性能通过                                                                                             |
| 真实设备与性能        | 当前合成浏览器检查不代表手机、平板或真实多盘性能                                                                                                                       |
| 真实文件表与 HDD       | 候选依次验证升级刷新、无变化增量、微博全量及封面；基于实测的文件表、读盘、核验与写库时间再决定优化范围 |
| 交付退役机制          | 后续单独核对启动脚本、交付路径和旧候选处置策略 |
| 旧管理维护入口        | 孤儿缩略图/目录用量、选择/清空日志、清空访问记录、备份载入草稿、删除检查报告、数据版本回滚/live 重置；后端存在不代表管理器已有入口，逐项等用户决定                     |
| 浏览细节              | MediaSession、默认/全屏宽度、复制媒体源地址、网格横滑、Windows 通知、Venera 精确搜索预设、侧栏版本号、通知中心、多规则组合排序；不按旧功能总账的“丢失”标记直接全部补做 |
| 界面专项              | 前端冻结已取消；当前后端功能保留，提示条、过滤器、账号和阅读界面的细节等用户试用后直接确定                                                                             |
| 压缩包分类            | 已记录各平台磁盘上的压缩包存在事实；细分类和 Gank 隐藏/封面规则等实地考察后确定                                                                                        |
| Runtime 归并          | 单独核对归属、占用、冲突及台账，不能擅停生产                                                                                                                           |
| 替换生产              | 当前候选与生产并行；是否替换及回退方式在验收后另行授权                                                                                                                 |
| 签名与自动更新        | 当前便携候选不因历史计划自动增加签名、安装包或自动更新                                                                                                                 |
| 非法 URL 错误正文     | Go parser 提前拒绝非法转义，现有差异见[读取架构](../design/architecture-http_read.md)                                                                                  |
| 目录重叠提示          | 提示中具体平台名等细节待后续确定，不改变当前路径保护                                                                                                                   |
| 独立 Gallery          | 保持独立，不假定与本项目数据库／协议兼容                                                                                                                               |
| gallery-dl 与下载校验 | Legacy 投入使用后的讨论方向；下载器保持独立，本轮不读下载数据或接入新能力                                                                                              |

存量限制见[技术债](debt-runtime.md)。
