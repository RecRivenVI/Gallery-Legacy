# 当前进度

## 当前状态

13.1.1 已接替旧版生产服务，后续开发和投放以当前 Go、Tauri、Compose/WasmJS 实现为基线。生产版本包含桌面浏览和灯箱改进、作者完成后入库、增量收尾核验、三个管理维护入口及访问审计升级。桌面和扫描改动见 [ADR-17](../design/adr-17-desktop_experience.md)，产品边界见[总览](overview-gallery.md)。

自定义播放器、Pixiv WebM 后台兼容切换和短片循环已投放生产，用户已试用新版播放。播放偏好和续播位置保存在浏览器，默认手动播放并在片尾停止。设计见 [ADR-18](../design/adr-18-web_video_player.md) 和 [ADR-19](../design/adr-19-video_compatibility.md)。

旧版及历史备份的审计已合并和归档，原备份已退役。生产核对了访问记录持续写入、服务就绪和现有图库统计。访问与封禁历史的保留规则见 [ADR-20](../design/adr-20-access_retention.md)，其他开放工作见[待办](backlog-runtime.md)。

## 验证边界

- 真实 NTFS 的 SSD 合成范围与原生打开结果对照了路径、大小、修改时间、扩展记录上的硬链接、稀疏和压缩文件。新作品目录、新作者的多层目录及子文件全部回放，和全量清单一致。目录移动和重解析点仍有范围重建或显式回退。
- 39 万件作品的合成文件清单验证了无变化时全数复用，修改一个文件时只重新处理对应作品。这个测量覆盖清单比对，实际作品处理与 HDD 耗时待测。
- 合成流水线验证已入库部分识别作品保留警告并复用，完全失败重试，未见媒体不被静默移除，作者范围、提前入库、取消和 HDD 顺序一致。
- 缩略图合成对照覆盖连接替换、缺表暂停、恢复队列及已有有效封面复用。后台作品升级覆盖暂停、停止、扫描交接、续跑和重启，合成微博只读取存在目标诊断的作品。
- 旧记录工具转换了 23 份扫描报告，保留其中 3 份失败。历史合并对照覆盖重复导入及保留现行封禁设置。访问审计的合成验证覆盖重启、跨旧上限、手动清空和分页。
- 旧候选的 57.9 分钟真实全量和 4 分 45 秒增量为背景。两次真实全量没有可比的冷热控制。当前候选的真实媒体、全平台完成时间和 HDD 性能留给用户试用。
- 13.1.0 实测首次作品升级耗时 68 分 41 秒。建立文件表基线的九平台增量耗时 8 分 02 秒。后续增量耗时 1 分 03 秒，清单耗时 16.4 秒，实际新增 1 件 X 作品。
- 新候选使用 39 万件合成作品测量首屏、滚动与开图。单独使用含真实媒体文件的合成小库对照原生维护操作和扫描顺序。
- 前端调整使用独立合成目录和可复用高分辨率媒体。两端有快速预览与优化构建，见[开发工作流](../development/workflow-development.md)。
- 画廊图片直接传递二进制，滚动时减少卡片文字的离屏绘制与页尾预取竞争。39 万作品的合成预览上，按产品封面尺寸模拟的滚动帧间隔 p95 中位数约 25 → 19 毫秒，三轮合计超过 50 毫秒的帧从 3 降到 0。高分辨率压力用例仍有长帧，首屏尚未得到稳定改善。浏览器核对了翻页、原图和管理端导航。
- 在合成预览中逐帧核对了横图、竖图的开合裁切，并延迟翻页响应，确认桌面和窄屏下页码条持续显示。第 1000 页的数字居中显示在圆角正方形按钮内，跳页编辑位置稳定。
- 桌面 Chromium 合成预览核对了单页换图的透明度和水平位置、双页换图、封面不参与阅读时的开合，以及网格与列表之间的等比裁切和重排。用有重叠作品的排序、筛选和分页响应核对了卡片身份保留。手指滑动和观感仍待实机复验。
- 桌面 Chromium 用合成视频核对了音量及播放设置持久化、字幕、拖动与悬停预览、续播、全屏、画中画和连播范围。窄屏模拟触控核对了播放、设置开合及被拦截后点按播放。移动设备上的系统音量、全屏和画中画留待实机核对。
- 合成浏览器验证了兼容切换保留自动播放意图、用户取消播放、原生循环和音轨策略。Windows Edge 的五帧样本在 20 次回绕中没有重复请求或显示缓冲提示，回绕帧间隔 p95 为 45 毫秒，片内为 44 毫秒。
- 用户已核对真实微博的增量与全量、输入法、托盘和目录选择。
- 冻结的试用构建通过 Go 测试、合成九平台扫描、增量复用、管理器本机操作与网页浏览检查。替换时核对了程序文件、回退副本、实例配置及数据库文件状态。
