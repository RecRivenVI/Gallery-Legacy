# 当前进度

## 当前状态

99／101 号第五步实现与合成验收已完成，当前源码的 Electron 管理器使用 Go 会话；在用生产入口与历史 Runtime 未切换。画廊与扫描只由管理器启动，隐藏窗口不结束任务，真正退出等待任务和服务关闭。决定见[adr-8](../design/adr-8-manager_lifecycle.md)，职责见[管理架构](../design/architecture-management.md)。

Go 已接管公共读取／媒体／文件浏览、全量与增量、范围选择、检查与报告、配置／访问管理、READY 组装发布、所有权及生命周期。任务直接调用既有 Go 流水线，不调用 Node writer；保留单 writer、完整作品事务、WAL/FULL 与源只读。Electron 仍负责窗口、托盘、系统对话框和固定白名单 IPC；旧 Node 后端及未迁移的旧验证场景保留到第六步，不将其存在称为已完成删除。

同一合成输入与冻结 Node 对照：九平台 71 件作品／284 个媒体、检查 108 条结果、配置与私有操作、静态 READY 被冻结 Node 接受；限定作者增量复用 8 件。管理器中途退出、主动取消、写入进程崩溃重开均保留已提交事实；Catalog 完整性、外键、Search 数量与事实一致。错误 token／实例、伪回复、重复所有者与外部启动拒绝有实际管道及原生身份依据。进程存活不再被误当成任务仍运行。

受影响包 race、构建、vet、实际 Electron／Go 桥及静态切换时的 WebSocket 关闭已验证。管理页实际操作包含扫描、立即封禁开关、访问筛选、端口保存并重启、停止／启动、隐藏和退出；深浅色四页、窄窗口放大及错误页共 13 张截图已查看。重复状态来源已收敛到管理器拥有的通道。复现见[场景](../../validations/scene-management/validation.md)，本机证据与候选入口位于仓外 GoControl-20261022；不是公开发行包或生产验收。

79／85 的基础差分继续有效：配置、schema、Reader、数据集、公共 HTTP／媒体／Venera／文件浏览已比较；未受影响的旧基础不重跑。两项已知公共读取差异见[读取架构](../design/architecture-http_read.md)。

Tauri／WasmJS 仍只有[原评估](../research/survey-tauri_wasmjs.md)和[范围补充](../research/survey-wasmjs_stack_scope.md)，不实施新栈，不迁 Miuix 组件或视觉；当前仍为 JS 驱动 CanvasKit＋原生输入／表单。[用户已接受的界面与许可范围](plan-go_backend.md)保持。本轮单主线程，不使用子代理、线程工具或 Goal。

## 开放项

- 字体正式分发、读屏、系统字号、输入法、真机、实际托盘点击与目录对话框未验收；原生 file 页面字体请求受 Origin 边界限制，现有回退不等于 MiSans 全语言通过。
- 错误页仍沿用笼统的“服务没有响应”；底层保留准确稳定码，完整用户错误文案另定，不将当前画面写成已完善。
- 任务聚合事实与范围字段可用；Go 静态报告没有复制旧 Node 的 inventory／内存采样／逐阶段计时私有遥测，不据此宣称全部诊断 JSON 位一致。
- 不同异常字段类型、真实多盘长任务、性能与真实浏览未在本次合成任务组穷举。已验证的行为不等同用户实际验收。
- Tauri／WasmJS 工具链版本、浏览器底线和宿主迁移顺序仍待决定；Miuix 组件不在候选范围。
- 生产与历史 Runtime、完整／空演示实例、用户冻结设计原文保持不动。手机既有性能与其他存量界面债务不借本轮扩范围。
