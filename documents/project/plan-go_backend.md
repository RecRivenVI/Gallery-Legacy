# 界面收尾与 Go 后端替换

## 目标

执行用户 2026-10-22 的 99／101 号检查点：完成第五步 Go 任务、本机认证、所有权与生命周期，接通现有 Electron 固定桥，并用冻结 Node 和合成实例验收后提交推送、汇报停止。79／85／92 已完成基础不重做。Tauri／WasmJS 继续只评估，不迁入 Miuix；生产实例与历史 Runtime 不动，不操作 Goal，不使用子代理。

## 范围

- 界面：接受 B 组四项，修正手机默认网格及同源加载占位；继续处理四项中实际可复现的对齐、零值和输入可用性细节。
- 许可：包信息与 README 使用 AGPL-3.0-or-later，LICENSE 全文和第三方 NOTICE 保持。
- Go：HTTP、Reader、媒体、schema／静态恢复、任务与本机控制生命周期；保留稳定链接、Venera、鉴权、进程身份与单 writer。
- 测试只生成合成实例；不接触真实配置、图库、历史 Runtime，不部署。不使用子代理或 Computer-Use。

## 最可能的风险

1. 编码、路径、错误码、缓存／Range 等边界与 Node 不一致：先冻结路由、请求、响应和失败语义，再用同一合成数据同时请求两个实现；字节、状态及必要响应头逐项比较。
2. 切换产生双 writer 或混库：每个实例只选一个后端；在独立实例内覆盖所有权、拒绝重复启动、取消／崩溃恢复及已提交事务保留，不在新后端调用旧 writer。
3. 管理器退出后残留运行、取消丢失已提交事务或外部入口仍能绕过管理器：按[生命周期决定](../design/adr-8-manager_lifecycle.md)绑定任务，先结束扫描再关闭服务；窗口隐藏不退出，真正退出等待资源释放，验证重新打开和外部拒绝。
4. 将 CanvasKit 底层 Wasm 误称为全面 WasmJS：按业务逻辑、绘制、输入、无障碍、媒体与宿主桥接分别调查，保留不可去掉的 Web API 胶水与待用户决定的工具链。
