# 原生控制、许可与界面状态修复

## 目标

原生管理窗口稳定完成四页轮询与服务生命周期；保持进程身份与实例认证强度。使用独立免安装工具链运行 race；原创代码采用与 Gallery 相同的 AGPL-3.0 全文。

## 范围

67 号授权：原生控制、生命周期、race 环境、许可及 A/B 组界面问题。生产、仓库外历史宿主、Runtime 迁移、剩余 Node 的 Go 化不在范围内。只使用正式入口和合成数据，不使用子代理或 Computer-Use。

最可能的三处风险与验证：

1. 用延长超时、重试或吞错掩盖控制阻塞：同一场景记录逐请求时间、错误和生命周期完成点，对照修复前后；不提高既有超时。
2. 控制修复弱化身份核验：验证 PID、创建时间、可执行路径、实例令牌仍同时匹配；保留伪造、PID 复用、失效所有者的拒绝测试。
3. 新编译器污染系统：工具链仅在 Scratches/Toolchains，CC/PATH 只对子命令生效；最小 race 程序前后对照，不修改既有工具安装或系统环境。
