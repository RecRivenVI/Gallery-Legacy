# 作品补充资料

固定平台抽取由 [字段表](../../internal/metadata/fields.go)、[补充字段表](../../internal/metadata/details.go)和具名复合解析函数定义，不接受外部规则。来源文件仍只补充物理作品事实。

类型、pixiv 分级、系列、前后篇、付费档位、工具与地区存入 可随快照保留的独立补充表；来源正文保留原文，展示和正文搜索使用去 HTML 的纯文本。`x_restrict` 只有 0/1/2 有分级含义，其他平台不产生分级。Pawchive 原平台与原 ID 不用于自动合并作者。

只保留 Fanbox 的 pixiv 对应键自动关联；其他平台只保留手动关联，不产生候选。具体公开投影以 api 契约为准。

升级在管理器持有维护所有权时执行。只打开库中记录的 metadata 路径，不遍历媒体或作品目录；已有磁盘媒体和稳定 ID 保留；元数据媒体声明及媒体行的旧元数据文件属性清空；停写的远端权限与结构化原文副本在重解析时清除。已提交的版本标记和补充行允许重新启动后继续，正常启动不重复解析已完成作品。
