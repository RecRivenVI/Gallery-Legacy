# 扫描文件清单

文件事实只来自磁盘目录枚举或经过完整性核对的 Everything 清单。增量逐文件比较，不计算文件内容或清单哈希；目录时间不参与变化判断。范围和交互决定见 [adr-14](../design/adr-14-scan_inventory.md)。

## 作品清单

`api/inventory.sql` 定义 live 格式的 `live_scan_files`：作品 ID、规范路径键、保留大小写的路径、字节数和修改时间（纳秒表示，按 Windows 100ns 精度比较）。目录行不进入此表。一个作品包含的全部文件都记录，包括 metadata、非媒体文件及嵌套叶目录文件。

作品、媒体、搜索、计数、版本和该作品文件清单在同一 WAL/FULL 事务中提交。解析失败不推进清单；未完成作品保留旧清单，下次增量重新处理。缺 metadata 的物理作品仍可入库。版本标记只表示解析规则兼容性，不是文件摘要。

全量不使用增量复用，逐作品替换；范围完整完成后才删除未见作品，删除还须原生确认不存在。增量仅替换文件清单不同或解析规则不兼容的作品。取消停止新的准备，排空已完成作品和写入队列，不对未完成平台进行删除收尾。

## 调度与进度

先获取所选平台清单，按条目数量排序。同一设备上的平台顺序执行，不同设备可并行。SSD 作者按作品数排序，准备并发根据作者文件数、作品数和全局上限调整。每块 HDD 一个读取者，整个平台按已知物理位置安排元数据读取；未轮到提交的作者结果暂存在实例磁盘，按作者作品数量的顺序发布。未知位置仍处理。

状态提供每个平台总作品/作者数、已扫描数、跳过数、失败数和问题详情。Venera 不提供作者级入口。总量在获取清单后才可用，不能以旧数据库数量冒充。

## 封面任务

封面任务独立于目录数据库，清单保存在缩略图数据库的 `cover_inventory`，队列在 `cover_jobs`。增量复用文件属性对应的已生成封面，全量重新生成所选范围。全部文件不进入预生成范围。

只手动启动。已有任务在扫描时暂停，扫描结束后由用户手动续跑；没有任务时不会自动创建。每块 HDD 一个后台源读取者，按源文件物理位置排序；浏览时实时请求优先。

## 升级

旧媒体声明表和兼容列保留在静态 Catalog 格式中，但不再写入。live 升级清空声明、旧元数据文件属性和被停用的自动作者对应键；文件清单首次扫描后才可认证增量复用。

## 文件类别规则

压缩包类别由 [ArchiveExtensions](../../internal/library/media.go) 的固定扩展名表识别，所有平台一致。存在压缩包时记录 `files.archivePresent` 及其磁盘相对路径，元数据中的文件声明不能产生此事实。压缩包本身不计入图片/视频媒体数；本轮不解压、不自动归并内容、不把其他平台套入 Gank 预览规则。Gank 的封面/预览页角色保持既有规则，其他细分类等实地考察后另定。
