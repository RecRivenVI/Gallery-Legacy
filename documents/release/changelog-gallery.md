# 更新日志

按语义化版本记录。当前尚无本次迁移的发布标签。

## [13.1.0] - 2026-11-09

### 新增

- 以 NTFS 文件表和变化日志生成扫描清单，清单不可用时可确认改用目录遍历。
- 提供旧管理端扫描报告、访问记录和日志的一次性导入工具。

### 变更

- 无变化增量批量核对文件事实，已完整入库的部分识别作品可沿用。
- 当前封面与其他缩略图分别存入 SQLite。阅读器显示原图，加载期间显示缩略图。

### 修复

- 修正 X 等平台的大整数 ID、Fantia 发布时间、Pawchive Fanbox 时区和后备字段警告。
- 缩短作者准备、作品排程和 HDD 入库排队等待，清理中断留下的任务清单。

## [13.0.0] - 2026-11-04

### 新增

- 全量和增量多选确认、独立作者扫描、逐平台作品/作者进度与全部失败和警告详情。
- 独立手动封面任务，支持平台和作者范围；访问页可配置默认关闭的自动封禁。
- 五秒自动刷新开关，与新内容提示并存。

### 变更

- 增量逐文件比较大小和修改时间，不使用目录时间或文件哈希；中断只保存已完成作品的清单。
- Everything 不可用时先提示，由你决定是否遍历目录。
- 每块 HDD 一个源读取者并按已知物理位置调度；SSD 根据平台/作者数量调整准备并发。
- 产品缓存、临时文件、日志轮转和旧数据版本清理直接释放空间。
- 视频时长在生成封面时从视频文件读取，与封面一起显示。

### 移除

- 元数据声明的媒体列表与文件属性；Patreon 与 X 自动关联、关联候选。

### 修复

- 全部文件隐藏已索引平台入口时不再产生错误诊断。
- 原生管理命令错误返回导致按钮一直等待的问题。

## [12.0.0] - 2026-11-03

### 新增

- 多词、排除和字段搜索，高级多平台搜索，包含/排除标签与类型、日期、分级、个人筛选。
- 本地多账号、收藏夹、评分、个人标签、历史、继续阅读及账号偏好同步。
- 作者页统计、跨平台关联候选确认，以及漫画双页、纵向连续、RTL 和系列切换。

- 固定九平台的作品类型、pixiv 分级与系列、付费档位、工具、热度指标及作者对应键。
- 分档缩略图、占位颜色、可暂停续跑的封面预生成和缓存容量设置。

### 变更

- 业务服务与扫描由 Go 承担；桌面管理器使用 Tauri，两端界面使用 Compose/WasmJS，保持既定设计，不引入 Miuix。
- 管理器拥有画廊服务和扫描生命周期；关闭窗口收起，退出等待任务正常结束。
- MiSans Global、Fluent System Icons 与共用主题用于两端；媒体、输入法和语义通过必要浏览器互操作接入。
- 官方 MiSans CSS 与全部子集原样随应用提供，断网中文可显示；不再运行时访问字体 CDN。
- 图片缩放改用随包 libvips DLL，视频首帧可配置 FFmpeg；作品详情显示清理后的纯文本与已有关系。
- 两端页面消费生成的数据类；旧实例按已记录 metadata 路径升级，不重新遍历媒体目录。
- 全量与增量优先使用 Everything 完整清单，不可用时原生遍历；未变作品复用，作品分批生效，大作品使用有界磁盘暂存，HDD 元数据按可用物理位置提示读取。

### 移除

- 产品 Node/Electron 宿主、旧 JavaScript CanvasKit 界面与已替代后端；Node 仅用于开发验证。

### 修复

- 分页／查看器保留稳定地址；窄屏不进入分栏；切换状态不自动刷新当前作品。
- 设置弹层焦点、数字跳页、完整窗口缩放及开关的辅助语义。
- Windows 状态读取与原子替换冲突导致更新提前失败；状态读写保留同步落盘与准确失败信息。
- 旧作者链接、指定媒体页、简介显示、图库检查筛选/分页/导出与托盘服务命令的迁移遗漏。
- 更新期间自动重载作品列表的问题，改为保留当前列表并合并新内容提示。

迁移不改变在用生产入口。验收范围和限制见[进度](../project/status-repository_standard.md)。
