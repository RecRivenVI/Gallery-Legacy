# 更新日志

遵循 Keep a Changelog；正式版本以发布事实为准，不为整理创建标签。

## 未发布

### 变更

- Go 标准库扫描器、CanvasKit 浏览和四页管理端迁入正式职责目录。
- 仍使用 Node 读取／媒体和 Electron 宿主；未替代部分明确列出。
- 原创代码采用 AGPL-3.0-or-later，许可全文保持不变。
- 管理窗口恢复默认／最小尺寸；宽窗口内容、零值与对外地址占位等四项细节按你认可的做法保留。

### 移除

- 被替代的旧 DOM 浏览与九页管理入口。
- 源码树中的阶段评审包、截图和运行结果；原件移至仓库外保留。

### 修复

- 终止扫描控制程序后，后台扫描也会停止，已经完成的作品保留。
- 原生管理窗口换页后可以继续读取状态、访问记录和日志。
- 服务读取失败不再与过期的“运行中”并列；错误不与空状态同时显示，运行环境检查有明确的等待和结果。
- 更新日期与画廊连接行显示实际最近更新时间，未配置文件目录时不留下空的分组。
- 手机默认“中”档按两列显示，加载占位跟随当前大小与封面比例；管理端短耗时不再显示“0 分”，缓存支持 GB，平台长名称不拆字换行。

本条不是上线声明。在用版本、实例目录和真实来源没有因本次整理切换。
