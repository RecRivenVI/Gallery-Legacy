# 新技术栈迁入正式源码

## 状态

已接受

## 背景

用户于 2026-10-21 经指定落实指令要求基于当前工作树采用仓库规范，将已经打磨的 Go 扫描 acceptance 链、CanvasKit 候选界面及四页管理端迁入正式位置；保留尚未被替代的 Node 部分，不新写 Go HTTP。

## 决策

- Go 扫描包放根模块 internal，入口放 cmd/gallery-scan；标准库遍历与唯一 WAL/FULL writer 不变。
- Node 残余服务按职责放 src，CLI 放 bin，浏览与四页管理放 public；不保留已被替代的旧 DOM 入口。
- 产品依赖、差分输入及可复用合成工具留在职责目录；阶段证据、旧 probe、截图、交付包移出仓库。
- 两份用户设计原文只移动、改名，不修改正文；其历史链接／格式作为用户指令与 D-04／D-10 的冲突明确保留。后续决定独立记录，不继续追加流水。
- 只有这次一个 Update 检查点与正常 main 推送获授权；没有历史改写、部署、Runtime 移动或在用服务操作授权。

## 后果

正式扫描不等于整个后端已经 Go 化。HTTP、读取、媒体、恢复及生命周期残余依赖在架构和技术债中明示。独立 Gallery 仍是另一仓库，后续迁入由用户另定。
