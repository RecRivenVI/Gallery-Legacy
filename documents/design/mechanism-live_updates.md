# 工作库与可见更新

显式 live 实例由扫描器写工作库，Go HTTP 读取已提交事实。一次完整作品批次同时维护 Catalog、Search、计数、revision 和文件清单，读者不能看到半件作品。

live epoch 是实例工作库身份；revision 表示可见提交。列表／游标绑定查询及版本，失配返回内容变化错误，不把不同修订拼页。媒体与分享使用物理身份，整数 rowid 不是永久业务身份。

作品准备好后进入有界队列，单 writer 按数量/字节和短时间窗口分批提交，不等待整个平台或巨型作者。作者定稿只在其全部作品核对完成后提交；删除仍须平台完整和原生不存在证明。

网页订阅聚合状态，按当前平台的 revision 合并到同一个新内容提示条；状态推送只标记列表有变化，五秒定时器合并取回当前页，不跳转或重载整个页面。自动刷新默认开启，用户可关闭；关闭时只保留提示条，用户点击才取回当前页。刷新可能移位，这是用户接受的行为。数量与侧边栏只更新变化的值。管理端把服务状态与扫描进度分开观察，进度变化不使导航和其他页面失效，不进行整页重载。日志仅在排查页读取。个人阅读数据按 adr-13，不与进度刷新混合。

失败／取消保留先前事务。工作库不双写候选，不在普通更新结束重建整个 Search，不自动生成最新 READY。恢复责任见[恢复机制](mechanism-recovery.md)。
