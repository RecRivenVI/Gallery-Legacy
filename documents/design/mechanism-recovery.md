# 恢复与静态数据

READY 是已经验证的不可变恢复来源，不是正在写入的工作库。工作库可以为空，也可从已验证检查点初始化；不能读取 BUILDING 或原地修改 READY。

Node 仍承担当下未被 Go 替代的 schema 初始化、静态构建／验证与显式恢复。保留这些能力不代表 live 扫描继续调用两套 writer；正式 live 入口必须只启动 Go。

正常 live 更新不创建最新检查点。已有 READY 不包含之后的提交；工作库损坏不能静默丢弃或退回旧视图。恢复／改根前必须确认无其他实例所有者，不在运行中替换数据库。WAL／SHM 与恢复材料完整保留。

Node 静态链及其差分基准的后续替代属于开放项；本轮不新写 Go 发布／备份系统，也不删除仍需的恢复实现。
