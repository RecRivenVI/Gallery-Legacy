# 作品信息后台升级与封面恢复

## 状态

已接受

## 背景

13.1.0 首次升级在服务就绪前逐作品读取 metadata。预览库的 SQLite 挂载随物理连接失效时，封面任务和本机状态读取同时失败。USN 将新目录与跨范围移动一并回退为文件表重建。

## 决策

- 结构升级仍在启动准备阶段。服务就绪后运行独立的作品信息任务，用户可暂停、停止和继续。任务沿用扫描写入租约和作品事务，交接时先释放租约。已入库作品继续可读。
- 通过已有目录事实核对 HDD 的 metadata 位置，按已知位置读取，未知位置照常处理。微博对象标题的历史修复通过逐作品诊断入队，使用独立规则标识。
- 缩略图 SQLite 在创建每条连接时挂载预览库。影响整个封面任务的读写故障暂停队列。重新排队时用当前媒体身份查已有效生成的封面。
- USN 先解析能证明父子关系的目录创建，再回放文件变化。改名、移动、删除和不连续的日志触发受影响范围的完整核对。

## 后果

- 升级进度与扫描进度分开。用户停止后仍可继续队列，已完成作品无需重读。
- 文件表日志记录平台、范围类型、处理方式和重建原因。
- 缩略图故障作为任务状态返回，其他管理状态继续可用。
