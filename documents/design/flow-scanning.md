# 扫描流水线

全量和增量共用文件清单、作品准备与唯一 writer；HTTP 与媒体服务保留独立读取连接。详细机制见[清单与扫描](mechanism-inventory.md)，持久字段见[文件清单](../reference/schema-scan_inventory.md)。

```text
选模式/平台或作者并确认 → Everything 清单（不可用先征求同意）
  → 平台/作者计数与排序 → 逐文件大小、mtime 对比
  → 未变作品复用；变化作品完整枚举、metadata 解析
  → 有界作品队列（HDD 物理读取与作者发布解耦）
  → 单 writer 短作品批次
  → Catalog + Search + 计数 + revision + 本批作品文件清单
  → 完整作者定稿 → 完整范围核对删除
```

- 全量逐作品替换，不先清空所选平台。增量以作品为最小单位，不看目录时间、不计算文件或清单哈希。
- 每块 HDD 一个源读取者；不同盘并行。SSD 根据作者作品/文件数选择有界并发，小平台、小作者优先。
- 首次或变化作品核对目录身份、重解析点和实际文件；metadata 只补作品和作者资料，不能制造或抹掉文件事实。
- 作品事务保持 WAL/FULL，同时更新检索与文件清单；取消停止准入，排空已完成的作品，不提前推进未处理范围。
- 作者资料只在完整作者处理后定稿；删除需完整范围并在磁盘上确认不存在。
- 失败与警告写入扫描问题文件，状态保留前 200 条预览，管理器可分页查看全部；阶段计时写入实例结构化日志。

不保证识别保留 size/mtime 的内容替换，不监控文件变化自动扫描。独立封面任务只由用户启动，扫描时暂停，结束后手动继续。
