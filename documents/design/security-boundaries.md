# 数据与管理边界

Source 永久只读。metadata 不授权文件读取；输出、缓存、数据库、日志、临时文件和 Electron 会话只能进入实例范围，不与来源重叠。

本产品不是账户服务或内容保密方案。公开读取意味着外部可读；robots/noindex 只是爬虫提示。管理操作走本机实例认证，不能凭 Host、IP 或转发的 loopback 请求取得权限。

路径／句柄／reparse／竞态校验及进程身份验证防止误写、错认实例和不完整删除；不能抵御拥有相同系统文件权限的恶意程序。无法验证身份就报告失败，不按 PID 猜测并终止。

公开源码只含人工夹具。真实验收不展示媒体、作者、正文、metadata 或私人配置，只保留聚合结果。字体不通过改扩展名、转码或编码绕开许可；已有合法外部资源不自动获得公共再分发授权。
