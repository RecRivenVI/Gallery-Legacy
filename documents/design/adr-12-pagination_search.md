# 页码与搜索行为

## 状态

已接受。依据：2026-11-03 用户确认并经外部评审转发的追加决定。本轮人工清单只保留中文输入、手机/平板打开和第一次真实扫描，界面细节改为自动验收。

## 背景

当前页码条的布局、滚动及翻页动效偏离冻结设计；搜索缺少立即提交、成组历史与快捷聚焦，越界页码错误地显示为空。

## 决策

1. 页码条恢复冻结 §6.6、§4.9、§5.4：内容底部居中悬浮的两块玻璃、间距 8，连续页码带、边缘渐变和悬停箭头，当前页尽量居中；手机使用 ‹ [12] / 108 ›。数字原地编辑，静态文字不移动。千页带仅绘制可见范围，以帧时间验证。
2. 翻页卡片从方向滑入 24，按 12ms 错开、最多 200ms；保留淡出和可中断滚动。越界页回到最后有效页并替换 URL。
3. 搜索继续 250ms 防抖，拼写期间不提交，回车立即提交；焦点会话的第一次变化新增历史，中间变化替换，回车或失焦结束该次会话。后退回到会话前状态。
4. / 在输入框外聚焦搜索，输入框内不拦截；搜索框补图标和快捷提示，手机可以展开/收起。所有筛选组合在翻页、刷新和历史导航中保留。
5. 浏览器自动验证以上操作并留图；旧行为差异在唯一功能对照中注明“按决定调整”。多关键词与搜索语法不纳入本轮。

## 后果

本轮便携候选需重新构建和验证受影响页面，不重跑真实扫描基线。原生自动启动受阻不以浏览器结果代替，但不再把界面细化检查交给本轮人工清单。
