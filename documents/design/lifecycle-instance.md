# 实例生命周期

实例配置和运行数据位于源码外。Node Runtime、Go 扫描器和 Electron 管理器是独立进程；关闭管理窗口隐藏到托盘，退出管理器不等于停止服务。

运行所有权由实例锁、进程创建时间和可执行身份共同确认，不凭 PID 推断存活。扫描入口先取得 scan 所有权，再初始化或打开工作库，最后将写入交给唯一 Go 子进程。停止扫描请求协作取消，不撤销已确认提交。

本机控制的 Windows 身份查询采用原生进程句柄，读回 PID、创建时刻和可执行路径；失败仍拒绝控制。Electron 的页内路由不改变可信文档，IPC 同时限制窗口、顶层 frame、精确文档与操作白名单，详见[原生控制决定](adr-3-native_control.md)。

Runtime 读工作库并发布聚合状态；扫描状态文件是可替换进度，不是作品事实。取消／失败不成为 READY；原生完整性核验失败阻止该范围删除。恢复检查点的不可变规则见[恢复机制](mechanism-recovery.md)。

源码迁移不改变任何在用实例：不复制真实配置、不切换安装、不重启服务。构建目录与运行实例都不能回到仓库中。
