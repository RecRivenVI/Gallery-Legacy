# 实例生命周期

实例配置与运行数据位于源码外。Tauri 管理器拥有 Go 会话，画廊服务与扫描只能从管理器启动。关闭窗口隐藏到托盘；真正退出正常结束任务和服务，保留已提交作品。

所有权由实例锁、进程创建时间、可执行身份、管道与令牌共同确认，不凭 PID 判断存活。身份不可核实时拒绝控制，不停止其他实例。

扫描请求协作取消；完整作品事务、Search、计数、revision 与增量签名一起提交。取消/失败不撤销已提交事实，不生成成功恢复基线。来源始终只读，缺失核验不完整时不得删除记录。

实际 IPC 与退出次序见[管理架构](architecture-management.md)，恢复边界见[恢复机制](mechanism-recovery.md)。源码迁移不安装、不迁移、不重启任何在用实例。
