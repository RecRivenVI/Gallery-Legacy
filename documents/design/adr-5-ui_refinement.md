# 手机网格与管理端细化

## 状态

已接受

## 背景

2026-10-22 用户认可 [B 组四项](adr-4-manager_details.md)，请在此基础上继续改进；同次指定的 72 号任务要求修正手机默认列数。按冻结基线 2、6.4、6.10、6.11 保持布局与文字简洁，不新增入口。

## 决策

- 手机默认“中”按可用宽度排两列，“较小”与“小”仍按目标宽度计算；竖屏触控网格至少两列、最多四列，列表不变。桌面目标宽度不变。
- 加载占位和真实卡片使用同一个几何计算，包括当前大小、比例和行距，避免加载后突然换列。
- 管理端一分钟以内不显示“0 分”；缓存按 MB／GB 显示，零值保留“没有缓存”。平台选择行保持单行与数字位置，长名称只在溢出时右侧淡出，不将英文拆字换行。
- 以上是按用户授权实施的细化，不冒称用户已逐项认可新外观。截图与功能证据位于仓库外 UiGoMigration-20261022 的第一阶段交付目录。

## 后果

原有交互、保存与动画不改变。手机与最小窗口需要用户试用；真实设备和读屏未因合成截图而验收。
