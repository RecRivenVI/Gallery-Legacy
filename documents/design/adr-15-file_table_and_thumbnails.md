# 文件表扫描与缩略图存储

## 状态

已接受

## 背景

真实全量暴露了清单后的排程开销。无变化增量仍重读部分识别作品，也重复收集增量用不到的物理位置。旧缩略图分档使同一媒体在实例里保存多份图片。

## 决策

- 以 Windows NTFS 文件表和 USN 变化日志替换 [ADR-14](adr-14-scan_inventory.md) 的 Everything 清单。不能确认日志连续时重读完整文件表。清单不可用须明确确认后才遍历目录。保留按文件大小和时间比对、按作品提交及删除的原生确认。
- 已完整提交的部分识别作品可复用。解析优先使用下载器的发布时间，平台字段作后备。Pawchive 的 Fanbox 无时区来源时间按日本时间解释。整数来源 ID 保留精确字符串。无标题社交作品由客户端按本地时间显示。
- 封面库和通用缩略图库均存 SQLite 图片 BLOB。当前封面保留，扫描成功后按目录补生成。通用库按最近使用回收，上限是封面有效图片字节和当前封面数估算中的较大值。封面及多用途图短边目标 540，纯底栏图 144，长边限制为三倍短边，小图不放大。阅读器加载原图。
- 旧管理记录经一次性工具导入停止的目标实例。归档原始扫描报告、访问快照、日志和一次性报告。保留失败状态，映射访问 ID 和事件，保留目标安全设置。目录库和短链接不导入。
- 自动验证只用 SSD 合成图库。用户授权只读核对真实键名、数值 ID、日期和结构形状，保留原始内容及生产实例隔离。旧记录导入演练可处理完整源文件，证据只提供聚合结果。

## 后果

- 每次用户发起扫描才访问卷和日志。文件表辅助进程独立提权。已提交作品的文件事实与临时清单分离，取消后已提交工作保留。
- 解析版本升级时从已索引路径刷新作品信息。旧目录、媒体和个人数据保持原身份。首次升级与无变化增量分开测量。
- 旧缩略图文件和索引原地保留用于回退，新库按实际用途重新生成。容量以图片有效字节计，数据库文件与 WAL 占用另列。
- 旧访问记录的重叠累计值取两边的较大值，近期事件按映射后的身份去重。旧版无细分日期的数据无法恢复为每日统计。
