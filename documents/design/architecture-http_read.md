# Go 公共读取接入

Go 公共读取已经有独立入口，但尚未替换 Node 默认服务。[行为合同](../reference/protocol-backend.md)仍是差分标准；[迁移计划](../project/plan-go_backend.md)中的任务、本机认证、实例所有权、动态恢复切换和进程生命周期仍待后续检查点。

## 模块与边界

| 位置                          | 职责                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------ |
| `cmd/gallery-read`            | 显式配置／前端／资源参数，组装读取服务、监听及退出；不是实例所有者，也不启动 scanner |
| `internal/httpservice`        | 公共 HTTP、Venera、静态文件、短链、状态 WebSocket 与访问封禁历史；没有管理 HTTP      |
| `internal/fileview`           | 已配置根的目录分页、递归搜索、文件 DTO、平台目录排除与链接拒绝                       |
| `internal/media`              | 源只读、MIME／Range／VTT，四并发缩略图队列、同目标去重、命中／生成、关闭取消         |
| `internal/library`            | 原有物理路径核验与统一实际媒体扩展名词汇；扫描和浏览共用，不改变资格语义             |
| `internal/instance`           | 配置与实例内原子 JSON 写入、废弃派生临时文件进入回收站                               |
| `internal/dataset`／`reading` | 已验证工作库／READY 数据集与同事务 DTO／revision；本轮不重新初始化已有工作库         |

HTTP 处理器不创建、升级或写 Catalog。短链、访问历史、缩略图和临时输出只写配置实例；真实源仍只读。当前独立入口只用于新合成实例，不具备防止另一个宿主接管实例的完整本机所有权协议，不能把它接到在用实例或作为生产启动方式。

## 请求与关闭

1. HTTP 校验既有访问封禁及 Host／Origin；WebSocket 按冻结 Node 只校验 Host／Origin，不因来源是 loopback 授予管理权。
2. 列表、详情、解析与章节在同一 Reader 事务内取得内容及 revision；列表同时保持 envelope／data 修订。状态聚合与其 revision 也从同一快照取得。
3. 媒体稳定路径与 k 身份在同一快照解析；随后按只读路径服务原文件。缩略图执行与请求等待分开，单个请求取消不取消其他等待者的任务；服务关闭则取消全部队列／编码器并等待退出。
4. 处理器创建成功后接管数据集；宿主先关闭 listener、排空普通请求，再关闭处理器。处理器关闭 WebSocket、缩略图、访问历史和只读数据库。

Venera 保留旧 DTO、旧媒体／目录接口与 source 模板。短链仍校验真实目标存在，持久化稳定 hash 目标；不新增备用控制入口。静态前端和字体／CanvasKit 根由启动方显式提供，不查找真实部署配置。

独立命令不枚举管理用的所有恢复点、不产生扫描状态，也不实现 applyGeneration。其状态回调只提供空的检查点列表和实际 live 标志，足以使用当前浏览 UI；完整运行状态由后续 Go 宿主接入回调。不能据此将管理四页或扫描生命周期写作已迁移。

## 可观察差异与验证

场景和复现命令见[HTTP 接入验证](../../validations/scene-http_read/validation.md)。原图、缓存、字幕、Venera、CORS、错误和状态事件以冻结 Node 的同一合成数据对照；Browser 使用未改动的当前网页。

保留的差异：Go `net/http` 在路由前拒绝路径中的非法百分号转义，返回 HTTP 400，但没有 Node 的 v1 JSON error／爬虫响应头；不为这一不可达于正常前端的请求自写 HTTP 解析器。冻结构建的 protocol.json 空白格式不同，当前 Node 与 Go 使用同一源码合同，解析内容一致，字节长度不同不算协议字段变化。其余未覆盖情形不推定等价。
