# 官方 MiSans 子集随应用分发

## 状态

已接受。依据：用户经外部评审转发的 2026-11-03 决定。取代 adr-10 的运行时小米 CDN 字体来源；其他便携版决定不变。

## 背景

用户要求断网时中文完整显示，且只使用小米官方发布的原文件，不自行制作子集或转换格式。Miuix 自带拉丁文件不属于本轮允许的官方源。

## 决策

1. 原样固定官方 index.css 与其全部 190 个 WOFF2 子集，获取与 SHA256 的唯一来源是 tools/fonts/misans.lock.json。文件在仓外缓存，构建逐项核对后复制到 resources/misans-cdn，字体二进制不进 Git。
2. 字体内容不改动、不自制子集、不转格式。官方 CSS 保持原字节；加载器仅把解析后的文件 URL 指向本地。ASCII 在多个官方子集中分布，预载契约选出的官方组合，不使用第三方 misans_latin.woff2。
3. 网页从同源资源路由按需读取；Tauri 通过固定的 gallery-font 虚拟协议读取同一资源目录，服务停止时管理器仍可加载字体。运行时 CSP 不放行小米 CDN。
4. CDN 未覆盖的九种小语种使用现有官方来源可变字体，Emoji 按需读取；不打包完整 CJK TTF 或 L3。应用内注明 MiSans，包中保留官方许可协议与版权通知。
5. 将阻断外部网络时中文、九种小语种、Emoji 的显示列入合成验收；桌面原生、真实输入法和手机实用仍须分别说明验证边界。

## 后果

资源增加约 12.7 MiB 的原始官方子集，但首屏只加载常用字符需要的组合。构建缓存与运行资源解耦，网页和桌面都不依赖外部字体服务。许可处理依据用户本次决定，原协议随字体保留。
