# 搜索与个人阅读

目录事实、共享作者关联和个人阅读分开保存。扫描只更新目录；个人数据不参与作品事务，不会因重建目录 ID 丢失。范围依据 [adr-13](adr-13-stage_two.md)。

## 查询

`internal/searchquery` 将语法解析为带原文范围的条件，界面用同一契约生成条件标签及高级字段。普通文字只匹配当前卡片可见字段；ID、正文和个人标签需要显式条件。多词可命中不同可见字段，全部满足才返回。

`internal/reading` 使用统一检索模板、紧凑可见字段投影和已有索引。个人筛选由只读连接附加个人库，以当前账号限定查询；跨平台必须有搜索条件。标签网址参数是 JSON 数组，保留标签自身的逗号。性能目标和合成测量见[搜索调查](../research/investigation-search_performance.md)。

## 个人库

`internal/personal` 管理实例内独立 SQLite，WAL/FULL、串行写连接。账号、会话、偏好、收藏夹、评分、个人标签及阅读进度均在这里；共享作者关联也保存在此库，但不按账号隔离。HTTP 请求以会话绑定账号，变更携带账号 ID，切换账号后的过期请求返回稳定错误，不修改新账号。

个人作品以平台和规范相对路径为键。扫描重建目录 ID 不影响关联；目录改名不猜测转移。删除收藏取消收藏夹成员关系；关闭记录历史保留旧记录，取消待写的阅读任务。界面串行提交个人变更，账号切换取消旧偏好和阅读任务并重新取得作品个人状态。

## 阅读

`ViewerReading` 选择单页、双页或连续方式；默认与跨页计算在公共 Kotlin 模型中。宽页独占，封面可单独显示；RTL 改变翻页、手势、缩略条和跨页顺序。连续模式只装入视口附近 L 档，超过 L 分辨率才读原图。

作品系列和前后篇来自元数据。打开相邻话同步背景列表位置；阅读进度按可阅读页计算，不含封面、点文件或提取预览。未知宽高不预读整本来推断长条；混合视频与动画保留单页播放。这些取舍在 ADR 中记录，待用户试用。
