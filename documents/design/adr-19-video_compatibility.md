# Pixiv WebM 兼容播放

## 状态

已接受

## 背景

试用实例的两个 VP9 WebM 样本分别出现循环中无限等待和播放错误。单独的浏览器媒体元素即可复现。两段源文件可软件解码。改换封装和重新编码成 VP9 仍复现，H.264 可正常播放。WebCodecs 能请求优先使用软件解码，但普通局域网 HTTP 页面不可用。

## 决策

- 按 [ADR-18](adr-18-web_video_player.md) 使用原生媒体元素。Pixiv WebM 优先播放原片。解码错误、异常提前结束或在已缓冲区间停滞时，对短视频自动尝试一次兼容播放。
- 服务端用实例配置的 FFmpeg 软件解码并生成 H.264 MP4。浏览器继续使用已有的控件和字幕，下载始终使用原始媒体地址。兼容响应和资源上限见[协议](../reference/protocol-backend.md#媒体与文件)。

## 后果

普通局域网 HTTP 可用。兼容播放需要 FFmpeg 的 H.264 编码能力，涉及一次有界的 CPU 转码；兼容内容只在请求和灯箱会话期间保留。浏览器仍为兼容流选择自身支持的解码器。
