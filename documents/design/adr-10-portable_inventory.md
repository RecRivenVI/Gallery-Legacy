# 11.0.0 便携版与清单驱动扫描

## 状态

已接受。字体分发已由 [adr-11](adr-11-bundled_misans.md) 替代；其余决定继续有效。依据：用户确认的 2026-11-03 便携版交付与扫描改造任务；该任务优先于旧方向。旧 ADR 原文不改。

## 背景

用户要求连续完成一次可直接使用的便携版交付，先核对旧产品的全部功能，再补齐迁移遗漏。HDD 连续扫描会改变缓存状态，本轮不另跑真实性能对照基线，也不在真实图库执行扫描。原样迁移检查点为 `878e7bc`。

## 决策

1. 保留 Go 业务后端、薄 Tauri 宿主与 Compose/WasmJS 两端界面，外观沿用冻结设计。目前不引入 Miuix 依赖；可直接移植其实现，保留 Apache-2.0 版权与 NOTICE。以后是否借用控件待定。
2. 字体采用 Miuix 的 MiSans 拉丁预载、官方 CDN Unicode 子集按需加载机制；CDN 不覆盖的小语种保留本地小字体，Emoji 按需加载。不打包完整中文字体或 L3。
3. Go 模块留根目录，Gradle 构建整体收进 `ui/` 并独立；`src-tauri/`、`tools/` 和根 `package.json` 保留。管理 UI 嵌入 Gallery.exe，网页 UI 通过 go:embed 嵌入 gallery-runtime.exe，不发行 frontend 目录。
4. 仅发行 Windows x64 便携版，版本 11.0.0，标识 `io.github.recrivenvi.gallerylegacy` 不变；exe 旁 `gallery.instance.json` 指向外部配置。包名 `Gallery_11.0.0_x64_portable.zip`，唯一顶层目录 Gallery，包含两程序、resources、LICENSE、NOTICE 和实例指针。resources 只含拉丁子集、Emoji、小语种字体及许可证。
5. 扫描只面向本机九根目录，允许依赖 NTFS/Everything。全量、增量优先用本机 Everything HTTP 清单；不可用、未加载或清单不合格时用现有原生遍历。清单完整性风险要先覆盖，不能把缺页/排除的结果当成完整扫描后删除。
6. 增量复用清单中 size/mtime/路径等签名没变的已提交作品，不读取其文件或目录；不检测内容替换但 size/mtime 都不变的情况。消失记录必须在磁盘确认不存在后才删除，不能凭清单缺失直接删除。
7. 作品准备好后经有界队列批量写入唯一 writer；不再等待整个平台或巨无霸作者完成。作者资料与删除在对应作者/平台完整收尾后定稿。保留完整作品事务、Catalog/Search/计数/revision 一致性、WAL/FULL、取消保留已提交事实及源只读。
8. 不新做账户、安装包、VLC 引擎或文件变化后自动扫描。按同日用户补充，HDD 全量的元数据读取按磁盘位置排序，允许必要的管理员权限；卷记录只保留范围内条目，测试只证明排序前后结果一致。日志记录分阶段耗时及元数据次数/平均耗时，真实效果由用户首次全量验收。
9. 交付到仓外 Portable 目录：压缩包、解开的 Gallery、独立 Instance。只从生产配置提取九个平台根目录，其他设置不迁移；用 Everything 只读核对每根的条目数，不读作品内容，不执行真实扫描。新空库、缓存、配置和端口与生产 8081 隔离。
10. 本任务连着做完，必要决定留最终汇报，不按中间检查点停下。允许原样检查点及相关阶段/最终提交，标题 Update，不推送、不建标签。生产程序、数据、配置和历史 Runtime 不动。
11. 同日补充纳入：频繁批次提交只产生有界合并通知，画廊不周期重载、管理器不整页重绘；大作品以有界磁盘暂存正常入库并测试恢复，不提高内存上限；pipeline/writer 按职责拆分，公共 API/UI 类型集中生成，内部错误链保留 %w 与 slog 上下文、公开码不变；字体许可逐项核对。
12. 非法 URL 错误正文对照旧实现；浏览器 /manage 按用户决定移除。验收清单首项中文输入，加入手机/平板访问，末项用户第一次真实扫描。同日收到 Kotlin/Compose 与 Tauri 正式附则，根 AGENTS 按 assembled 原字节同步；版本目录、CSP 和项目规范去重遵循新附则。

功能对照的唯一来源为 [功能对照](../research/review-feature_parity.md)。`src-tauri/`、`tools/` 与根 package.json 的位置不动，内容可正常修改。Runtime 归并、替换生产、签名和自动更新仍不在本轮。

## 后果

11.0.0 的基本功能验收用合成输入与旧行为对照；实际设备和第一次真实扫描由用户验收。CDN 断网时缺少尚未下载的中文子集，离线全中文不作为本次交付保证。清单来源和写入时机变更需覆盖假完整、失败/取消与作者收尾，不能降低源只读和持久化要求。版本由 Cargo 声明作为便携版构建来源注入 Go，未获授权不创建 Git 标签（本任务对版本来源的明确决定优先）。
