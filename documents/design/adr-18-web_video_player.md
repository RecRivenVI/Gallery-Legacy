# 网页视频播放器

## 状态

已接受

## 背景

用户要求定制画廊网页播放器，记住音量、循环与自动播放，并以 YouTube 的常用播放功能作为参照。媒体由现有 Go 接口提供，视频与图片共享灯箱和媒体选择。

## 决策

- 用 Compose 实现画廊播放器控件。浏览器媒体元素负责解码、缓冲、音轨、字幕和媒体 API。
- 播放偏好存在浏览器。打开时自动播放与播完后的动作独立设置。默认手动播放并在片尾停止，连播限于当前作品相邻的视频。
- 近期续播时间按作品、媒体路径和大小记录，在打开视频时提供继续按钮。桌面进度预览延迟取样并在退出预览时释放解码资源。
- 灯箱切走媒体时先停止播放，保留动画所需的画面。实际交互见[视频播放](../usage/guide-gallery.md#视频播放)。

## 后果

播放格式、系统音量、全屏和画中画取决于浏览器及设备能力。播放偏好和视频进度按网站来源和浏览器保存。
