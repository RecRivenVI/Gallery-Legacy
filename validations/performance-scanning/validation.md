# 扫描性能比较

## 目标

区分冷／热盘、枚举、核验、准备、Catalog／Search／持久提交与服务响应成本，不用降低持久化换成绩。

## 运行

1. 另获真实扫描授权，固定范围、源码／binary、来源绑定、并发和批次；每轮独立空库，明确全量或增量。
2. 关闭 CPU 堆栈采样；不并行测试或清理；串行记录阶段墙钟、累计计时、读取、RSS 和状态探测。
3. 冷盘以用户确认的自然状态记录，不预读／清缓存；后续自然热盘保留所有轮次，不挑最快。
4. 运行后只核对完整性、外键、统计、Search 镜像与账本聚合；不浏览内容，结果留仓库外。

## 通过标准

来源只读、完整性和 WAL/FULL 不变；报告“ 一致／有差异／无法比较”及范围。不同平台范围不直接算倍数；并行累计不可相加当墙钟，盘级计数不等于进程独占 I/O。没有具体证据不宣称硬件极限。
