# 新栈完整场景

## 目标

验证 Go、Tauri、两端 Compose/WasmJS 的可用核心路径、旧入口退役和管理器绑定生命周期。只使用生成器新建的合成实例；不读真实配置或图库，不控制生产。

## 运行

1. 按[开发流程](../../documents/development/workflow-development.md)构建新的仓外候选，生成至少每平台 32 件作品的合成完整实例与独立端口；另用 `-works 0` 生成空实例。
2. 启动该候选，显式传入合成配置；仅本次验证为 WebView2 设置回环 CDP 参数。核对 exe、创建时间、实例与端口，不根据 PID 或名称推断归属。
3. 设置 `GALLERY_TEST_CONFIG`、`GALLERY_TEST_CDP`、`GALLERY_REVIEW_OUTPUT`，依次运行 `npm run test:native`、`npm run test:browser`、`npm run test:interactions`。所有生成路径和 native 当前配置必须在同一合成根；脚本会先核对。动效片段使用环境中的 FFmpeg 编码。
4. 检查深浅色四页管理器、桌面/平板/手机的作品、作者、全部页、文件、设置、查看器及加载/失败画面。实际看过截图再写说明。
5. 使用 CDP 的触点事件验证翻页、双指缩放、手机抽屉，录制不超过 10 秒的打开/关闭中断、主题、侧边栏及翻页片段。
6. 在自己启动的测试候选内验证隐藏/重新显示、正常退出、退出期间协作取消以及重新打开。校验子进程的完整身份，确认 Go 退出、端口和租约释放、已提交数据仍可读。
7. 禁用本次 CDP 环境参数，重新打开合成候选供用户试用。记录系统输入法候选窗、原生目录选择、实际托盘与真机仍需人工检查。

## 通过标准

看大图的可见打开中断可单独执行 `node tools/validation/viewer_interrupt.mjs`，使用同样的合成配置和输出变量；必须等看大图实际出现后再取消，不能把请求尚未完成时的取消称为动效中断。

- 主要浏览、搜索/清除、筛选、翻页、查看器、分栏与管理操作符合当前设计，失败能重试，保存失败保留输入。
- 完整合成扫描的事实/媒体数量与输入一致；增量复用已提交作品；SQLite 完整性、外键和状态计数一致。
- 原生管道身份、来源与操作白名单未放宽；公开管理页没有本机控制能力；生产没有被操作。
- 真正退出后自己的 Go 会话结束，已提交事实保留；隐藏窗口仍可继续运行。
- 必要单元、race、编译与功能检查有实际结果；人工项与未运行的旧黄金差分不记为通过。
