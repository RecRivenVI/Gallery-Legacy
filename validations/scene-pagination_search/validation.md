# 页码和搜索

## 目标

按 adr-12 自动验证两块悬浮玻璃页码、千页带、数字原位编辑、方向翻页和搜索。优先核对三项风险：搜索会话是否污染历史；1,080 页是否生成全部节点或产生长帧；输入法拼写是否误触发查询。真实系统输入法仍在三项人工清单中。

## 运行

使用 tools/demo 的完整合成实例和同源码公共读取入口。设置 GALLERY_TEST_CONFIG、GALLERY_REVIEW_OUTPUT，录屏另设 GALLERY_FFMPEG，运行 `node tools/validation/pagination_search.mjs`。所有请求限于隔离回环地址；规模场景只覆写合成响应的页数，不访问真实图库。帧时间场景不与构建或扫描并行。

真实帧时间使用 `GALLERY_TEST_BROWSER_CHANNEL=chromium`，记录浏览器、渲染器与原始间隔；默认 headless shell 的软件渲染结果单列，不能当作硬件渲染结论。可用 `--pager-only` 或 `--mobile-only` 单独复验受影响场景。

翻页方向另运行 `node tools/validation/pagination_motion.mjs`，设置 GALLERY_MAGICK 为 ImageMagick。使用合成彩色标记和受控浏览器时钟，从截图像素核对正反位移与后排延迟；该时钟只证明功能轨迹，不用于帧率结论。

## 通过标准

- 条件的 16 种有无组合经过翻页、跳页、刷新和后退仍一致；超范围回最后页并修正 URL。
- 搜索 250ms 后自动触发，回车立即触发；CDP 合成 composition 期间不请求。一次输入会话只增加一个历史条目，后退恢复会话前状态；/ 聚焦但不拦截输入框内字符；手机可展开收起。
- 页码条居中悬浮、不占整行；数字编辑不移动静态文字；手机没有可见“第/页”；页码带只创建可见页、边缘箭头符合剩余方向、当前页居中/端点停靠。翻页带有方向和错开动画。
- 1,080 页带使用真实浏览器 rAF 帧间隔记录，不以平均 FPS 掩盖长帧；按冻结标准核对错过帧与 50ms 长帧。输出原始间隔与摘要，截图和录屏只作留存。
