# 画廊浏览场景

## 目标

验证 Compose/WasmJS 的主要页面、查看器、分栏、主题与响应式，保持当前设计和稳定 URL。

## 运行

1. 按[新栈场景](../scene-full_stack/validation.md)构建并通过管理器填充合成实例。
2. 执行 `npm run test:browser`，在桌面、平板、手机尺寸检查深浅色；运行时阻止非回环请求。
3. 查看每张截图，覆盖加载、空、筛选空、错误、无效网址及主要动效中断；检查图片、动图、视频的实际加载和释放。
4. 用户检查输入法候选窗、触屏真机、读屏与系统字号；未测的项目保持未验收。

## 通过标准

核心操作与当前设计一致，不用旧 JS 页面回退；静态资源及字体从本地取得，错误可以重试；卡片隐私模糊不蔓延到其他区域。编译、语义树和自动触点不代替实际读屏/真机体验。
