# 浏览与管理场景

## 目标

使用完整／空合成实例验证 Canvas 浏览、四页管理与 Go 扫描接线；不访问生产或真实内容。

## 运行

1. 按开发工作流准备独立实例、固定 Go 可执行文件和合法外部 UI 资源。
2. 运行现有 Node／Go 单元、host 与 incremental／native 集成定义；记录仓库外输出。
3. 自动窗口默认 1920×1080、静音，分别预设深／浅主题后打开作品、筛选、翻页、关闭、分栏和管理四页；响应式用目标尺寸。
4. 合成实例执行一次更新、未变增量、取消、封禁开关和设置保存。截图只用合成素材，写说明前实际查看图。
