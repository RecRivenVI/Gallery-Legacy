# 原生管理窗口

## 目标

验证 Tauri 管理器的四页、精确本机控制与退出；不放宽创建时间、可执行路径、实例与管道身份。具体步骤统一在[新栈场景](../scene-full_stack/validation.md)。

## 运行

1. 新建合成实例并启动自己构建的 Gallery.exe；记录完整进程身份与回环端口。
2. 执行 `npm run test:native`，检查四页、开关立即生效、保存/重启、停止/启动和检查结果。
3. 检查窗口默认/最小尺寸与深浅色，手动检查文件夹选择器和托盘；正常退出并核对 Go 结束和租约释放。

## 通过标准

只接受精确的管理文档和原生会话；重复或未知所有者不能接管。四页核心操作一致，真正退出绑定服务与任务。截图只含合成内容；人工项目不由源码或编译替代。
