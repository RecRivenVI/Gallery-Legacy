# 合成大库检索

## 目标

在 390,000 个合成作品（其中微博 270,000）上测量查询、精确计数和 48 张卡片投影，先记录现有实现，再决定新语法的目标。语料没有真实文件，不代表扫描、媒体读取或浏览器性能。

## 运行

1. 使用 SSD 上全新的仓外目录作为 `<root>`，仓外证据文件作为 `<output>`。
2. 不同时运行其他测试、构建或清理。
3. 从仓库根执行 `node tools/go/run.mjs run ./tools/searchbench -create -root <root> -output <output>`。
4. 后续候选使用同一语料，去掉 `-create`，保存全部样本，不只挑最快的一次。

## 通过标准

语料总数和九平台分布一致，来源读取为零；相同语义的结果数量一致。每项预热一次后测九次，报告中位数和 p95（小样本取最大值）。新语法的数值目标和适用范围记录在第二阶段 ADR，不能把查询时间宣称为端到端交互时间。
