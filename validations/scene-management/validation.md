# 管理功能与生命周期

## 目标

验证 Go 管理会话经 Tauri 操作可用，保持单 writer、源只读与协作关闭。

## 运行

1. 按[新栈场景](../scene-full_stack/validation.md)启动独立合成候选，执行 `npm run test:native`。
2. 从管理器执行全量、增量、检查、设置保存与重启；访问封禁开关立即生效，无设置保存条。
3. 分别隐藏、正常退出以及在自己的测试任务期间退出，核对进程身份、服务端口、租约与已提交数据；不停止任何其他实例。

## 通过标准

界面、Go 状态与数据库聚合一致；失败不变成成功；取消或退出保留已提交事务；原生控制不依赖公开 HTTP 或宽松身份回退。实际托盘/输入法/系统文件对话框单独记录人工结论。
